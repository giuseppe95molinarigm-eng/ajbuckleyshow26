# Photography: generation prompts

These images were generated with FLUX 1.1 Pro Ultra via Replicate (`raw` mode, 1:1). The generator is `source/generate_images.mjs`, which needs `REPLICATE_API_TOKEN` set in the environment and never stores it.
Files are saved as `source/images/<slug>.jpg`, and the build places them automatically with `object-fit: cover`.

**Frame:** 286.5 × 270 pt (3.98 × 3.75 in), ratio about 1.06 : 1.
**Minimum size:** 1200 × 1125 px for 300 ppi effective. The generated images are 2048 px.
